# 预测市场：前置知识与数学依赖

这份仓库把“如何理解、评估并实现预测市场”拆成可循序学习的知识图谱。重点是概率预测、市场定价与机制设计；不构成投资建议。

## 学完后应能做什么

- 把事件判断表达为概率，并说明概率来自哪些信息与假设。
- 理解价格何时可以近似解释为概率，以及流动性、风险偏好和机制如何造成偏差。
- 计算并解释 Brier score、对数损失和校准误差。
- 看懂订单簿、做市、套利和 LMSR 等基本机制。
- 用小型模拟比较不同市场机制，而不是只凭直觉讨论价格。

## 学习路径与数学依赖

```text
代数、函数、对数与指数
          ├──> 概率论 ──> 贝叶斯推断 ──> 概率预测与更新
          │       └────> 统计推断 ──> 校准、评分规则、回测
          └──> 微积分 ──┐
线性代数 ────────────────┴──> 优化 ──> 做市与机制分析
效用与决策理论 + 博弈论 + 市场微观结构 ──> 激励与市场设计
```

### 1. 基础工具（可与数学并行）

- Python 基础、表格数据处理、绘图；能读写 CSV 并复现实验。
- 会读函数图像，理解百分比、比率、求和符号；掌握指数、对数和基本代数变形。
- 不需要先成为软件工程师；先用短脚本检验概率、价格和评分规则的例子。

### 2. 概率论（核心必修）

事件与集合、条件概率、独立性、全概率公式、贝叶斯公式、随机变量、期望、方差，以及常见离散/连续分布。随后理解大数定律和中心极限定理。

**用途：**表达预测、更新信念、计算合约期望收益，并区分“事件概率”与“某个模型给出的估计”。

### 3. 统计推断与预测评估（核心必修）

抽样、似然、最大似然估计、置信区间、假设检验、过拟合和数据泄漏。重点掌握概率校准与适当评分规则：二元 Brier score ` (p-y)^2 `、对数损失 `-[y log(p)+(1-y) log(1-p)] `。评分应在明确的数据切分与基线下比较。

**用途：**判断预测是否可靠，避免只用命中率评估概率预测；理解历史频率、样本量和不确定性。

### 4. 线性代数、微积分与优化（理解机制时必需）

先学向量、矩阵、内积、导数、偏导数、梯度；再学凸函数、约束优化和梯度下降。深度学习所需的高阶优化内容不是入门门槛。

**用途：**理解多结果市场的状态表示、价格作为成本函数的边际变化，以及做市参数如何影响价格和风险。

### 5. 决策理论、博弈论与市场微观结构

期望效用、风险厌恶、信息不对称；策略互动与激励；订单簿、限价单/市价单、买卖价差、深度、滑点、流动性和价格发现。它们不是纯数学的先修课，但决定了“价格为何不等于真实概率”。

### 6. 预测市场机制（综合应用）

- 二元合约：若合约在事件发生时支付 1、否则支付 0，其价格可作为概率的粗略信号；融资成本、风险偏好、交易约束和流动性都会影响解释。
- 订单簿：理解报价、成交、价差、深度与库存风险。
- 自动做市：理解流动性参数、边际价格、成本与最坏情形损失。
- LMSR（对数市场评分规则）：多结果情形下常见成本函数为 `C(q)=b·log(Σᵢ exp(qᵢ/b))`，边际价格为 `pᵢ=exp(qᵢ/b)/Σⱼ exp(qⱼ/b)`。理解它需要指数/对数、偏导数和归一化；实现时还要注意数值稳定性。
- 结算与预言机：学习结果定义、争议处理、结算延迟和操纵风险。若研究链上市场，再补智能合约与安全知识；不是理解预测市场数学的前置条件。

## 建议的实践顺序

1. 写一个二元事件预测表，记录预测概率、时间戳、最终结果和信息来源。
2. 用 Python 计算 Brier score 与对数损失，并与“总预测基准概率”的简单基线比较。
3. 画可靠性图，检查预测概率与实际发生频率是否一致。
4. 模拟一个二元订单簿，观察深度、价差和大额订单对成交价的影响。
5. 实现小规模 LMSR，验证价格和为 1，并观察参数 `b` 对价格变化与做市风险的影响。
6. 对比订单簿与自动做市机制，并明确假设、局限和失败案例。

## 先学什么 / 暂时可以跳过什么

**最短入门链路：**基础代数与对数 → 概率论 → 贝叶斯更新 → 统计评估与校准 → 订单簿和二元合约 → LMSR。

**可后置：**测度论、随机微积分、连续时间金融、深度学习、复杂合约安全审计。只有研究相应主题时再补，不是预测市场入门的通用门槛。

## 术语边界

“市场价格是概率”不是无条件定理。它通常是特定合约、结算规则、参与者、资金约束和交易机制共同形成的信号。学习时应始终问：支付函数是什么？谁能交易？流动性有多深？结果如何裁定？

## 市场机制速览

<details>
<summary>AMM（自动做市商）</summary>

### Automated Market Maker

AMM 是一种通过**自动定价机制**提供交易报价的市场机制。交易者可直接与流动性池或做市机制交易，不必等待另一位交易者逐笔匹配订单。

- **流动性来源**：通常来自流动性提供者（LP）存入的资产，或由机制/协议提供的抵押资金。
- **价格形成**：由资金池状态和预设定价公式决定。
- **典型公式**：`x × y = k`（恒定乘积模型，是 AMM 的一种常见设计）。
- **主要特点**：交易会改变池中资产的相对数量，从而影响后续交易价格；交易规模相对流动性越大，价格冲击通常越明显。

**Example:** Uniswap。

</details>

<details>
<summary>CLOB（中央限价订单簿）</summary>

### Central Limit Order Book

CLOB 是一种通过**集中展示并撮合买卖订单**实现交易的市场机制。交易者提交限价订单，撮合系统通常按价格优先、时间优先等规则处理订单。

- **流动性来源**：市场参与者提交的买入和卖出挂单。
- **价格形成**：由订单簿中的买方报价（Bid）与卖方报价（Ask）共同形成。
- **买卖价差**：`Spread = Best Ask - Best Bid`。
- **主要特点**：大额订单可能消耗多个价格档位，产生滑点和价格冲击；订单簿深度反映不同价格上的可交易数量。

**Example:** Polymarket。

</details>
