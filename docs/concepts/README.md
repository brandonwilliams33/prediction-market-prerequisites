# 预测市场概念

本分类解释预测市场中的核心对象和术语。建议先理解合约与结算，再讨论价格是否能代表概率。

## 预测市场是什么

预测市场围绕一个未来事件或可验证结果创建合约。参与者基于信息买卖合约，市场价格随供需、信念、风险偏好和交易约束变化。

## 事件合约与支付

以二元合约为例，若事件发生时支付 1 单位、未发生时支付 0，合约到期支付可写为事件指示变量。交易前需确认事件定义、截止时间、结算来源和争议规则；模糊的判定条件会使价格难以解释。

## 价格与概率

二元合约价格有时可作为事件概率的近似信号，但不应直接等同于客观概率。流动性、手续费、资金成本、参与者风险偏好、仓位限制及结算风险都可能造成差异。应同时考察合约支付、市场深度和结算规则。

## 流动性与价格发现

- **流动性**：在不显著改变价格的情况下完成交易的能力；常从价差、深度和滑点观察。
- **价格冲击**：交易改变可成交报价或市场状态的程度。
- **价格发现**：市场参与者将信息反映到交易价格中的过程；价格是信号，不保证准确或无偏。
- **套利**：利用相互关联合约间的不一致定价建立组合；现实中会受费用、执行风险和资金约束影响。

## 结算与预言机

结算规则规定如何把现实事件映射为合约结果。中心化市场可能由运营方裁定；链上市场可能依赖预言机及争议机制。研究市场时应检查数据来源、裁定窗口、争议流程和结算延迟。
