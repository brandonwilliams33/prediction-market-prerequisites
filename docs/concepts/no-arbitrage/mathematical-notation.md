# 数学符号约定（Mathematical Notation）

本页约定本文讨论有限状态预测市场时使用的符号，尤其用于无套利定价和支付向量分析。

> 这些字母是本文为方便说明采用的记号，不是数学领域或 Polymarket 的官方统一符号标准。论文、代码或平台文档可能采用不同定义；阅读时应以具体上下文为准。

| 符号 | 英文名称 | 本文含义 |
| --- | --- | --- |
| `Ω` | State Space | 所有允许的结算状态组成的集合。 |
| `ω ∈ Ω` | World State | 一个具体的结算状态。 |
| `I` | Contract Index Set | 可交易合约的索引集合。 |
| `i ∈ I` | Contract Index | 某一合约的索引。 |
| `p ∈ ℝ^I` | Price Vector | 各合约当前价格组成的向量。 |
| `pᵢ` | Contract Price | 第 `i` 个合约的价格。 |
| `φ: Ω → ℝ^I` | Payoff Mapping | 将一个结算状态映射为各合约支付向量的函数。 |
| `φᵢ(ω)` | Contract Payoff | 状态 `ω` 下第 `i` 个合约的支付金额。 |
| `y ∈ ℝ^I` | Portfolio Vector | 各合约的持仓向量；正数表示多头，负数表示空头（仅在允许相应交易时）。 |
| `y · φ(ω)` | Portfolio Payoff | 持仓 `y` 在状态 `ω` 下的总支付。 |
| `p · y` | Portfolio Cost | 按价格向量 `p` 建立持仓 `y` 的初始净成本；不含费用、保证金和融资约束。 |
| `M` | No-Arbitrage Price Set | 在明确的支付、计价和交易假设下，使可交易组合满足无套利条件的价格向量集合。 |
| `μ ∈ M` | Consistent Price Vector | 无套利价格集合 `M` 中的一个价格向量。 |

## 关系与假设

若结算状态有限，且存在一个状态概率分布 `q`，则其对应的期望支付价格向量可写为 `μ = Σ_{ω∈Ω} q(ω) φ(ω)`，其中 `q(ω) ≥ 0` 且 `Σ_{ω∈Ω} q(ω)=1`。所有这类期望向量构成支付向量 `φ(ω)` 的凸包。

在适当的无摩擦、支付折现、交易可行性和市场完备性等假设下，这种凸组合表示可用于刻画无套利价格。一般情形下，`M` 的确切范围取决于可交易合约、现金/ numeraire 约定、交易约束和状态价格条件；因此，不能脱离假设把 `M` 简单定义为“所有允许支付向量的凸包”。

这里的 `q` 只是解释价格向量凸组合时引入的状态概率符号，不预设为真实世界概率，也不意味着市场价格必然是客观事件概率。

## 阅读建议

- `φ(ω)` 描述某个状态下合约实际支付什么；`p` 或 `μ` 描述合约现在的价格，两者不是同一个向量。
- `y` 描述交易组合。是否能持有负仓位、能否按报价成交，需要结合具体市场规则判断。
- `M` 是模型下的价格集合，不代表某个平台公布的官方价格区间。
