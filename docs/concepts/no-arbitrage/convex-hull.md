# 凸包（Convex Hull）

凸包是包含一组点的**最小凸集合**，直观上可理解为用橡皮筋包住所有点所形成的区域。

## 在有限结果市场中的含义

设市场有有限个互斥且穷尽的结算状态，合约在各状态下的支付组成向量。若以现金为计价单位、支付已折现，并假设无摩擦、可自由交易且不存在约束，则一致的价格向量可表示为各结算状态支付向量按某个概率分布加权的期望；因此，它落在这些支付向量所张成的凸包内。完整、无套利市场的定价还需结合可交易支付空间与状态价格等条件，不能仅凭画出一个支付向量集合就推断所有现实价格。

## 示例：两个互斥且穷尽的结果

A、B 是仅有的两种结果，两个 YES 合约在各结算状态的支付为：

- A 发生：联合支付向量 `(1, 0)`
- B 发生：联合支付向量 `(0, 1)`

在上述归一化假设下，二者的无套利价格向量是这两个点的凸组合，满足 `p_A + p_B = 1` 且 `p_A, p_B ≥ 0`。几何上，这是一条从 `(1, 0)` 到 `(0, 1)` 的线段。

例如 `(0.6, 0.4)` 在这条线段上；`(0.6, 0.6)` 不在，因为 `0.6 + 0.6 = 1.2`。

## 注意

- 这里的凸包是**价格向量**由状态概率加权形成的集合；任意市场、任意合约的定价集合都不一定简单等于原始支付向量的凸包，需先明确状态、支付和计价约定。
- 手续费、Bid/Ask 价差、资金成本、流动性、卖空限制、抵押品要求和结算风险都会改变可执行的无套利边界。
