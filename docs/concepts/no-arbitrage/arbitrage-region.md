# 套利空间（Arbitrage Region）

在有限结果市场的无摩擦定价模型中，可将**无套利价格集合之外的价格报价**视为潜在套利区域。它表示理论上存在可构造的组合，不意味着现实中一定能以显示报价成交或锁定利润。

## 如何理解

- **凸包内部或边界**：在本分类所述的简化模型和归一化约定下，价格满足无套利一致性条件。
- **凸包之外**：报价违反该模型的价格一致性条件；若相关合约可按所需方向和规模交易，可能构造理论套利组合。
- **偏离程度**：与无套利集合的距离可用作模型中的定价偏差指标，但不等于可实现利润；成交价、深度、手续费及持仓限制都可能吞噬差额。

## 示例

若 A、B 互斥且穷尽，且 YES 合约分别在对应结果发生时支付 1，则归一化的无套利价格满足 `p_A + p_B = 1`。报价 `p = (0.6, 0.6)` 的总价格为 `1.2`，高于完整结果集合的单位支付；在允许相应交易方向并忽略成本的理想模型中，可通过卖出/做空相关合约构造套利。若只能买入、无法卖空，或实际 Ask/Bid 与深度不同，这个结论可能无法转化为可执行交易。

## 实际检查清单

1. 确认结果是否互斥且穷尽，合约是否使用相同的结算定义与时点。
2. 按可成交的 Bid/Ask 计算组合成本，而非只比较屏幕中间价。
3. 检查各档订单簿深度、手续费、滑点、卖空/仓位/抵押品限制。
4. 核对结算来源、争议流程与时间风险，并计算最坏情形支付。

**要点：**凸包外的报价是理论套利信号；能否套利，取决于可交易组合与真实执行条件。
