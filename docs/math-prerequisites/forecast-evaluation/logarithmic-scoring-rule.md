# 对数评分规则（Logarithmic Scoring Rule）

对数评分规则（log score）是一种**严格适当评分规则**：预测者报告其真实主观概率时，可使期望得分最大。此处采用“得分越高越好”的记号；在机器学习和统计评估中常见的对数损失（log loss）是其相反数，因此是越低越好。

## 定义

对二元事件，令 `p` 为预测者报告的事件发生概率，`X∈{0,1}` 为实际结果，则：

`S(p,X) = X ln(p) + (1-X) ln(1-p)`

因此：

- 事件发生（`X=1`）：`S(p,1)=ln(p)`。
- 事件未发生（`X=0`）：`S(p,0)=ln(1-p)`。
- 对应的对数损失为 `L(p,X)=-S(p,X)`。

通常取 `0<p<1`。若报告概率为 0 或 1，而实际结果被赋予零概率，则得分趋向负无穷、对数损失趋向正无穷。

## 符号

| 符号 | 含义 |
| --- | --- |
| `p` | 预测者报告的事件发生概率，`0<p<1`。 |
| `r` | 预测者对事件发生的真实主观概率。 |
| `X` | 实际结果；事件发生为 `1`，未发生为 `0`。 |
| `S(p,X)` | 对数评分函数；本页约定得分越高越好。 |
| `ln` | 自然对数。 |
| `Eᵣ` | 按主观概率 `r` 对结果取期望。 |

## 严格适当性

当真实主观概率为 `r` 时，报告 `p` 的期望得分是：

`Eᵣ[S(p,X)] = r ln(p) + (1-r) ln(1-p)`

对 `0<r<1`，该期望在 `p=r` 时唯一取得最大值：

`Eᵣ[S(r,X)] ≥ Eᵣ[S(p,X)]`

且当 `p≠r` 时严格大于。于是，如实报告自身概率比报告其他概率有更高的期望得分。这是关于期望得分的性质，并不保证单次结果中诚实预测一定获得较高分。

## 实际使用注意

- 对不同预测进行比较时，需在同一结果定义和可比样本上评分，并与基准预测比较。
- 对数损失对极端错误预测惩罚很大；应检查概率生成和数据质量。
- 实作中有时将概率裁剪到 `[ε,1-ε]` 防止无穷数值；裁剪会改变评分的边界行为，应记录使用的 `ε`，并避免把裁剪后的结果误称为完全相同的原始评分规则。
- 该规则评估概率预测，不直接衡量交易收益或市场报价是否可执行。
