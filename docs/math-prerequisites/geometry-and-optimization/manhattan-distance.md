# 曼哈顿距离（Manhattan Distance / L1 Distance）

曼哈顿距离，又称 **L1 距离**，是两个向量各坐标差的绝对值之和。二维点 `P=(x₁,y₁)` 与 `Q=(x₂,y₂)` 的距离为：

`d₁(P,Q) = |x₁-x₂| + |y₁-y₂|`

它可理解为城市方格道路上只能水平或垂直移动时的最短路程。对 n 维向量，`d₁(P,Q)=Σᵢ |Pᵢ-Qᵢ|`。

## 衡量价格到无套利集合的距离

设 `C` 是在特定支付、计价和无摩擦假设下定义的无套利价格集合。价格向量 `P` 到该集合的最小 L1 距离为：

`dist₁(P,C) = min_{Q∈C} Σᵢ |Pᵢ-Qᵢ|`

因此必须在整个集合 `C` 中寻找距离最小的点，而不是任意挑选一个点。

- **距离为 0**：当 `C` 为闭集时，`P` 位于 `C` 内；在对应简化模型下满足该集合表达的无套利一致性条件。
- **距离大于 0**：`P` 位于 `C` 外；在模型假设下显示价格向量不一致，但并不自动保证现实中可执行套利。
- **距离更大**：表示按 L1 度量的几何偏离更大；它不是利润估计，实际套利空间还受成交方向、订单簿、费用、头寸和结算约束影响。

## 示例：两个互斥且穷尽的结果

在归一化的二元市场中，无套利价格集合为 `C={(q,1-q) | 0≤q≤1}`。取市场价格 `P=(0.6,0.6)`。例如 `Q=(0.5,0.5)` 是该线段上的一个最近点：

`d₁(P,Q)=|0.6-0.5|+|0.6-0.5|=0.2`

这里最近点并不唯一：任意 `Q=(q,1-q)` 且 `0.4≤q≤0.6` 都达到最小距离 `0.2`。所以价格点到无套利凸包的最小 L1 距离为 **0.2**。

## 解释边界

- 结果需互斥且穷尽，合约支付和价格归一化约定需一致；否则示例中的线段模型不适用。
- L1 距离依赖坐标表示和尺度。若改变合约单位或重复/重组坐标，距离数值可能改变；比较前应固定表示方式。
- 理论上位于无套利集合外，不代表 Polymarket 或其他市场上一定能获利。应按可成交 Bid/Ask、可用深度、手续费、交易限制、抵押品和结算风险重新评估。
- 对实际最优距离问题，可将绝对值引入辅助变量，转化为线性规划；需明确集合约束及可行交易组合。
