# 数学前置

本分类按依赖关系整理理解预测市场所需的数学与实践工具。无需先掌握高等数学全部分支；优先学概率、统计评估和市场机制所需的微积分/优化。

## 依赖路线

```text
代数、函数、对数与指数
          ├──> 概率论 ──> 贝叶斯推断 ──> 概率预测与更新
          │       └────> 统计推断 ──> 校准、评分规则、回测
          └──> 微积分 ──┐
线性代数 ────────────────┴──> 优化 ──> 做市与机制分析
效用与决策理论 + 博弈论 + 市场微观结构 ──> 激励与市场设计
```

## 数学主题

- [几何与优化](geometry-and-optimization/README.md)：向量距离、凸集及约束优化；包括衡量价格向量偏离无套利集合的 L1 距离。

## 1. 基础工具

- Python 基础、表格数据处理和绘图；能读写 CSV 并复现实验。
- 理解函数图像、百分比、比率、求和符号、指数、对数和基本代数变形。
- 可与数学学习并行，不需要先成为软件工程师。

## 2. 概率论（核心）

事件与集合、条件概率、独立性、全概率公式、贝叶斯公式、随机变量、期望、方差及常见离散/连续分布；随后理解大数定律和中心极限定理。

**用途：**表达预测、更新信念、计算合约期望收益，并区分事件概率与模型估计。

## 3. 统计推断与预测评估（核心）

抽样、似然、最大似然估计、置信区间、假设检验、过拟合和数据泄漏。重点掌握概率校准与适当评分规则：二元 Brier score 为 `(p-y)^2`，对数损失为 `-[y log(p)+(1-y) log(1-p)]`。应在明确的数据切分与基线下比较。

**用途：**评估概率预测质量，避免只用命中率，并理解样本量和不确定性。

## 4. 线性代数、微积分与优化

先学向量、矩阵、内积、导数、偏导数和梯度；再学凸函数、约束优化和梯度下降。深度学习所需的高阶优化内容不是入门门槛。

**用途：**理解多结果市场的状态表示、成本函数的边际价格，以及做市参数如何影响价格和风险。

## 5. 决策理论、博弈论与市场微观结构

学习期望效用、风险厌恶、信息不对称、策略互动与激励；同时了解订单簿、限价单/市价单、买卖价差、深度、滑点、流动性和价格发现。这些不是纯数学先修课，但有助于解释价格为何不等于真实概率。

## 实践顺序

1. 记录事件预测概率、时间戳、结果和信息来源。
2. 用 Python 计算 Brier score 与对数损失，并和简单基线比较。
3. 画可靠性图，检查预测概率与实际发生频率是否一致。
4. 模拟订单簿，观察深度、价差和大额订单对成交价的影响。
5. 实现小规模 LMSR，验证价格和为 1，并观察流动性参数的作用。
6. 对比 [AMM](../market-mechanisms/amm.md) 与 [CLOB](../market-mechanisms/clob.md)，写明假设和局限。

## 最短入门链路

基础代数与对数 → 概率论 → 贝叶斯更新 → 统计评估与校准 → 订单簿与二元合约 → LMSR。

可后置测度论、随机微积分、连续时间金融、深度学习和复杂合约安全审计；只有研究相应主题时再补。
