# 基于效用的做市商（Utility-Based Market Maker）

基于效用的做市商用效用函数表达风险偏好，并结合主观状态概率和不同结果下的财富，确定交易价格。一个常见原则是：通过选择交易价格，使交易者与做市商交易前后的**期望效用相等**（效用无差异定价）。这描述的是模型中的定价方法，不保证现实市场的效用或概率可被准确观测。

## 效用函数与风险厌恶

效用函数 `u(m)` 把财富 `m` 映射为效用。严格递增的凹效用函数表示风险厌恶；例如对数效用 `u(m)=ln(m)` 的定义域要求 `m>0`，且边际效用为 `u'(m)=1/m`。

## 状态价格与边际定价

在有限个互斥且穷尽的状态、完全状态索赔、货币作为计价物、状态概率为 `θᵢ>0` 的设定下，若做市商在状态 `i` 的财富为 `mᵢ>0`，其归一化的状态边际价格可写为：

`pᵢ = θᵢ u'(mᵢ) / Σⱼ θⱼ u'(mⱼ)`

此式表示状态概率乘以该状态的边际效用，再归一化使 `Σᵢ pᵢ=1`。它是完全状态索赔设定下的边际定价关系，不是任意市场中所有合约的通用报价公式。对有限数量的交易，通常需用效用无差异条件求解，而不能只把交易前的边际价格当成整笔交易价格。

### 示例：对数效用

做市商对 YES 和 NO 的主观概率各为 `0.5`，两种结果下当前财富分别为 `m_YES=80`、`m_NO=100`。取 `u(m)=ln(m)`，则 `u'(m)=1/m`：

`p_YES = (0.5/80) / (0.5/80 + 0.5/100) ≈ 0.556`

因为 YES 状态下财富较少，其边际效用较高，故该状态索赔的边际价格高于主观概率 `0.5`。这不表示事件的客观概率因此变成了 `0.556`。

## 恒定期望效用与有限交易

若交易前状态财富为 `mᵢ`，状态索赔交易后增加或减少财富 `Δmᵢ`，一种效用无差异条件为：

`Σᵢ θᵢ u(mᵢ + Δmᵢ) = Σᵢ θᵢ u(mᵢ) = k`

其中所有相关状态都须满足效用函数定义域（对数效用时 `mᵢ+Δmᵢ>0`）。交易价格可被求解为满足该条件的现金转移量。此处的 `k` 是给定交易前组合的期望效用水平；实际模型还必须说明交易者的合约支付如何映射为每个状态的 `Δmᵢ`，以及现金在各状态如何计入财富。

## 对数效用下的条件性损失界限

假设做市商初始财富为 `W>0`，最终状态 `i` 下财富为 `mᵢ = W - L(q,i)`，且 `θᵢ>0`、做市商始终保持有限的期望对数效用。由于 `ln(mᵢ)` 要求每个正概率状态下 `mᵢ>0`，可得：

`L(q,i) < W`

因此，在这些假设和该损失定义下，任何结算状态中的净亏损都小于初始财富 `W`。这不是无条件的机制保证：若存在外部负债、额外资本流、不同损失定义、概率为零的状态或实现层风险，须另外分析。该界限也不同于标准 LMSR 的 `b ln(n)` 损失上界。

## 与 LMSR 的区别

| 比较项 | 基于效用的做市商 | 标准 LMSR |
| --- | --- | --- |
| 主要输入 | 主观状态概率、效用函数和状态财富 | 份额向量与流动性参数 `b` |
| 定价直觉 | 状态概率按边际效用调整 | 成本函数梯度给出边际价格 |
| 损失界限 | 依赖效用、初始财富、概率和模型约束；不一定存在通用界限 | 在标准假设下，上界为 `b ln(n)` |
| 主要建模难点 | 需选择主观概率和风险偏好 | 需选择 `b` 并承担模型规定的最坏情形上界 |

参见 [LMSR 成本函数](lmsr/cost-function.md) 和 [LMSR 有界损失](lmsr/bounded-loss.md)。

## 局限

- 主观概率 `θ=(θ₁,…,θₙ)` 通常难以可靠估计；概率设定会直接影响价格。
- 效用函数的形式和参数表达做市商的风险偏好，选择不同会改变报价。
- 状态价格公式依赖状态索赔可交易、归一化和财富/现金约定；不完整市场、交易限制和摩擦可能改变定价集合。
- 模型中的损失界限不覆盖手续费、融资、违约、预言机错误、智能合约漏洞或运营风险。
