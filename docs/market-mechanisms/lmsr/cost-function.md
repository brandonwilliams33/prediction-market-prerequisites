# LMSR 成本函数与交易支付

LMSR（Logarithmic Market Scoring Rule）使用成本函数随市场份额状态变化而自动报价。定义：

`C(q) = b ln(Σᵢ₌₁ⁿ e^(qᵢ/b))`

其中 `qᵢ` 是结果 `i` 的净份额状态，`b>0` 为流动性参数，`n` 是互斥且穷尽的结果数量。买卖引起份额变化 `Δq` 时，按成本函数计算的净支付为：

`Cost(Δq) = C(q + Δq) - C(q)`

该差值可以为正或负：正值表示交易者净支付给做市机制，负值表示机制按模型向交易者净支付。实际产品仍可能另加手续费或采用不同结算/交易规则。

## 边际价格

对成本函数关于各结果份额求偏导，得到该结果的边际价格：

`pᵢ(q) = ∂C(q)/∂qᵢ = e^(qᵢ/b) / Σⱼ₌₁ⁿ e^(qⱼ/b)`

因此各结果边际价格非负，且总和为 1。单笔交易的平均成交成本则由交易前后成本差决定，不一定等于交易开始时的边际价格。

## 符号

| 符号 | 含义 |
| --- | --- |
| `C(q)` | 份额状态 `q` 对应的累计成本函数值。 |
| `q` | 各结果净份额组成的向量。 |
| `qᵢ` | 结果 `i` 的净份额状态。 |
| `Δq` | 本次交易引起的份额变化向量。 |
| `b` | 流动性参数，`b>0`。 |
| `n` | 互斥且穷尽的结果数量。 |
| `pᵢ(q)` | 状态 `q` 下结果 `i` 的边际价格。 |
| `e`、`ln` | 自然指数底数与自然对数。 |

## 流动性直觉

`b` 越大，份额向量变化同样大小时，边际价格通常变化越平缓；但标准 LMSR 的最坏情形损失上界 `b ln(n)` 也随之增大。详见[LMSR 风险限制](bounded-loss.md)。

## 与对数评分规则的关系

LMSR 的名称及构造与对数评分规则相关，但应区分：对数评分规则用于给概率预测打分；LMSR 成本函数用于根据市场份额状态计算交易成本和边际报价。见[对数评分规则](../../math-prerequisites/forecast-evaluation/logarithmic-scoring-rule.md)。
