# LMSR（对数市场评分规则做市商）

LMSR（Logarithmic Market Scoring Rule）是一种自动做市机制。它通过成本函数为多结果市场报价；交易者改变结果份额向量时，成本函数给出所需支付。它可视为把对数评分规则用于市场做市的机制，但**评分规则与做市成本函数不是同一对象**。

## 条目

- [LMSR 成本函数与交易支付](cost-function.md)：定义成本函数、增量交易成本及其边际价格。
- [LMSR 风险限制（有界损失）](bounded-loss.md)：说明标准 LMSR 的 `b ln(n)` 最坏情形损失上界及成立条件。

## 关键直觉

- `b` 是流动性参数：在其他条件相同的情况下，`b` 越大，价格对份额变化越不敏感；标准模型的最坏情形损失上界也越大。
- LMSR 可在无需等待对手方提交匹配订单的情况下提供报价，但这不代表现实实现没有费用、资金、合约或结算风险。
- 其最坏损失界限来自指定的成本函数和结算支付假设，不自动覆盖部署、预言机或运营风险。

## 其他做市定价方法

[基于效用的做市商](../utility-based-market-maker.md)根据主观状态概率和边际效用调整状态价格；与 LMSR 的成本函数定价及其 `b ln(n)` 上界不同，其报价和损失界限依赖效用模型、财富与概率假设。
