# CLOB（中央限价订单簿）

**Central Limit Order Book** 是一种集中展示买卖订单并按撮合规则成交的市场机制。交易者可提交限价单；撮合系统通常按价格优先、时间优先等规则处理订单。

- **流动性来源**：市场参与者提交的买入和卖出挂单。
- **价格形成**：订单簿中的买方报价（Bid）与卖方报价（Ask）共同形成可交易市场。
- **买卖价差**：`Spread = Best Ask - Best Bid`。
- **深度与冲击**：大额订单可能消耗多个价格档位，导致滑点和价格冲击；订单簿深度描述不同价格上的挂单数量。
- **执行风险**：挂单不保证成交；行情变化、撤单和流动性不足都会影响执行结果。

**Example:** Polymarket 的交易市场以订单簿机制为核心示例；具体产品实现和交易规则应以其当前文档为准。

**数学关联：**排序、累积数量、价差、成交均价和滑点计算；更深入的分析涉及概率、风险和市场微观结构。
