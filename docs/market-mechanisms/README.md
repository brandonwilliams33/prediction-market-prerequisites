# 市场机制

本分类收录预测市场组织交易、提供流动性和形成价格的机制。当前条目：

| 机制 | 核心方式 | 适合了解的问题 |
| --- | --- | --- |
| [AMM（自动做市商）](amm.md) | 按定价规则自动报价，交易者与池或机制交易 | 公式如何影响价格、深度和价格冲击？ |
| [CLOB（中央限价订单簿）](clob.md) | 集中展示买卖挂单并按撮合规则成交 | 报价、价差、深度和撮合规则如何影响交易？ |
| [LMSR（对数市场评分规则做市商）](lmsr/README.md) | 通过凸成本函数连续报价，并将风险限制在模型上界内 | 成本如何随交易变化，流动性参数如何影响价格和风险？ |

机制比较时，关注流动性来源、定价/撮合方式、交易成本、价格冲击、库存或资金风险，以及结算和交易约束。价格并非脱离机制的纯概率读数。
